# PCB 贴装助手

本地 Windows 程序，用 EasyEDA 专业版工程生成锡膏印刷定位夹具、元件备料盘，每种工具同时输出 STL 和实体 STP。

## 启动

双击 **`pcb_helper/main.pyw`** 启动，不会弹出命令行窗口。它通过 Windows 的 Python 启动器选用现有 Python 3.12；没有创建 `.venv`，也没有修改系统默认 Python 指向。需要查看命令行错误时仍可运行同目录的 `pcb_helper/start.cmd`，两种方式使用同一个 Python 入口。CadQuery 建模库会在首次生成实体时加载，因此主窗口可以更快出现，首次建模可能多等约 2 秒。

当前开发验证环境：Python 3.12.2、PySide6-Essentials 6.11.2、CadQuery 2.8.0、VTK 9.6.2。VTK 和 NumPy 已在原环境中，无需为本次改动另行安装。此前依赖文件合计约 **1.32 GiB**（含建模库的传递依赖；不是虚拟环境重复占用）。精简 Qt 包没有安装不需要的 Qt Addons。

本次仅将应用源文件集中在 `pcb_helper/`，尚未制作安装包或独立 EXE。若直接将源码复制到另一台电脑运行，对方仍需 Python 3.12 和 `pcb_helper/requirements.txt` 中的依赖；不能把当前文件夹当成免安装发行版。

## 使用

1. 点击“导入工程”，选择 `.eprj2`。有多个 PCB 时，必须选择其中一个。软件内的“使用帮助”提供完整的操作说明。
2. 选择“锡膏印刷定位夹具”或“元件备料盘”，再选顶面/底面。只有插装或忽略元件的板面置灰；未知安装类型需要先确认。
3. 使用备料盘时，在元件表中核对安装类型。可将元件改为贴装、插装或忽略。夹具模式隐藏元件表；工程标记不装配/不加入 BOM 的元件默认忽略，其原始属性仍保存在结果报告中。
4. 修改左侧参数，查看布局预览中的尺寸与冲突提示。所有单位为 mm，间隙均为**单边**；倍率没有长度单位。打印范围 X/Y 的新配置默认值均为 256 mm，对应拓竹 A1 的标称成型空间；已有配置值不会自动更改。
5. 点击“生成实体并预览”。实体未生成时三维页禁用；生成后三维页默认采用接近俯视的正交视角，以减少薄板在斜视角下的形变观感，并用轮廓线突出槽和侧壁。左键平移、右键旋转、滚轮以鼠标下的位置为中心缩放；中键与其他未定义操作不触发三维交互。布局页在所有模式下都可按住右键平移视图，平移模式还可用左键平移；画面随鼠标拖动方向移动，滚轮以鼠标位置为中心缩放。窗口缩放不重置视角；参数变化会使旧三维实体失效并返回布局页。
6. 点击“导出 STL + STP”，选择输出目录。每次建立独立时间戳子目录，避免覆盖已有成果。

生成后若修改参数、元件类型或尺寸，旧实体失效，必须重新生成后才能导出。工具各自记住板面选择。

导入工程、生成实体和导出时会显示不可关闭的 0–100% 进度框；期间界面暂时锁定。导入按已处理历史数据行数推进，建模与导出按已完成的实际步骤推进。CadQuery 的单次布尔运算没有内部进度，因此这类步骤的百分比会暂时停留，完成后再前进；百分比不是剩余时间预测。所有检查结束后才显示 100%。

### 定位夹具

- 默认完整底面支撑，按背面没有元件设计；底板和侧壁默认各 1 mm。
- 默认外围余量 3 mm、PCB 厚度 1.6 mm、钢网厚度 0.12 mm、单边间隙 0.2 mm。这些都是试验起点，不代表已经适配实物。
- 壁高从**底板上表面**开始测量。默认 1.72 mm 与上述 PCB 加钢网厚度相等；修改厚度后应同步核对壁高。
- PCB 与钢网两段侧壁可以使用不同间隙。间隙差必须小于壁厚，避免上下壁脱离。
- 缺口表中的位置是沿当前板面板框周长的百分比，宽度是局部切向开口宽度。预览会显示实际切除区段；可以添加、删除或修改缺口。
- 板框曲线以圆弧实体生成，STP 不把原圆角离散成三角网格。底板不会因板上的通孔而自动挖空。
- 此夹具只用于锡膏印刷，不作为加热台上的回流治具。

### 元件备料盘

- 默认每个位号一槽，按原位置与角度排列。元件表中宽高是**封装局部坐标系的占用尺寸**，不是旋转后的水平包围框。
- 初始尺寸来自器件形状与焊盘包络，属于建议。仅有焊盘时会单独标明。特别是连接器、开关等，务必核对实物引脚和本体。
- 双击宽高修改。尺寸修改后需要重新勾选“已确认”；也可以多选行，点击“确认选中尺寸”。确认表示你接受这些尺寸，不是软件已经验证实物。
- “备料标注”列默认按工程属性自动建议：电阻、电容、电感显示数值，部分二极管、晶体管和保险丝显示简短型号，IC 默认不刻字。点击“自动生成标注”会重算当前 PCB 全部元件并覆盖先前手改内容；也可以直接编辑或清空单个单元格。此功能使用本地规则，不需要 API 密钥。
- 二维预览上方可切换“平移视图 / 移动凹槽 / 移动标注”。移动模式下左键拖动相应对象；重叠时选择鼠标附近中心最近的对象。移动标注期间，会以固定 11 像素宽的虚线连接该标注与所属凹槽的中心。二维文字采用与三维雕刻相同的 CAD 字形轮廓和位置。槽和标注的 X/Y 可在元件表中精确输入（单位 mm），标注字号也可逐项覆盖；字号留空表示沿用左侧全局值。修改凹槽位置时，该元件标注跟随移动；单独移动标注不影响凹槽。PCB 原始坐标不变。
- 备料盘右上角可收起或展开元件列表；收起后预览占满右侧。列表展开时，拖动预览与列表之间的横向分隔线可调整列表高度；再次展开会恢复之前的高度。
- 元件表可按表头排序，可搜索位号、属性、标注、封装，并可筛选板面或安装类型。拖动表头分隔线调整列宽；尺寸依据显示短写法、悬停可看完整说明；封装按可用宽度显示省略号、悬停可看完整名称。元件“类型”需点击下拉选择，鼠标滚轮只滚动列表，不会误改类型。
- 默认凹槽单边取放间隙 0.5 mm、最小隔墙 1 mm。相交或隔墙不足的槽以红色显示并在报告中提示，但仍可生成；相交槽成为连通凹槽。尺寸待确认、超出打印范围或实体无效等仍会阻止生成。
- 调整“槽中心间距倍率”只拉开槽中心，不放大槽尺寸；可再手动移动单个槽，不自动拆盘或优化布局。
- 大于配置的打印范围时阻止生成。打印范围是你提供的可用平面尺寸，不会自动检测打印机。
- 雕刻内容来自“备料标注”列，空白则不雕刻。文字重叠仍雕刻；落在盘顶的部分从顶面向下雕刻，落在槽内的部分从槽底向下雕刻，不雕刻槽侧壁。文字移到原盘外会扩展盘体，再检查最终打印尺寸。字号/字体无效、无可雕刻材料、刻穿底板或超出打印范围会明确报错。
- 盘的 +Y 边缘有三角形方向缺口，布局预览不显示方向提示文字。底面采用沿板中心竖轴翻面的视角。

## 导出内容和配置

每次导出得到：

- `*.stl`：毫米约定的打印网格。
- `*.stp`：实体 STEP，可导入 CATIA 后修改；不包含 CATIA 原生草图和参数历史。
- `report.json`：源文件摘要、选定板面、参数、元件修正、实际尺寸和验证结果。
- `元件清单.csv`：位号、属性、备料标注、封装、尺寸与确认状态。中文 UTF-8 BOM 编码。

“保存”写回当前配置文件；“另存为”建立并切换到新配置文件；“打开配置”切换文件。配置只包含左侧参数（含缺口、备料标注开关和打印范围），与 PCB 工程无关。修改后关闭程序或打开其他配置会提示保存、放弃或取消。下次启动会打开上次使用的配置文件，其位置记录在 `pcb_helper/output/recent_config.json`；应用目录内的配置记相对路径，以便移动整个目录。本机原有的 `output/配置.json` 已复制到 `pcb_helper/output/配置.json`，旧文件保留作备份。旧版会话文件如放在应用的 `output/` 内，可仅迁移参数；不恢复 PCB 或元件修正。元件表人工修改只在当前程序运行中保留。

所有样例与 `test_doc` 工程均保持只读。应用默认导出位置、配置和错误日志在 `pcb_helper/output/`；开发测试生成的验证材料仍在项目根目录的 `output/`。发布时不应包含 `test_doc/`、`tests/`、根目录 `output/` 或个人配置数据。

## 当前支持范围

- 已验证提供的 EasyEDA 专业版 3.2 系列 `.eprj2`：读取 SQLite 当前分支历史链、校验并解码记录、处理记录删除和文档删除。
- 支持直线、圆弧、圆及矩形/圆角矩形板框，拒绝未闭合、断开、多独立轮廓及尚未支持的曲线，不拿包围矩形顶替。
- 对同一条完全相同的闭合板框被重复记录的情况，只保留一圈；其他自交轮廓仍按无效输入处理。
- 备料盘布局可先显示已确定的贴装元件；未知安装类型会列为待确认、暂不绘槽，并在确认前阻止生成。
- `Sleep Station.eprj2` 已检查出 10 块 PCB；`Main`、`Main_2`、`Main_3` 的待确认元件不会再使布局完全空白，`LIGHT` 的重复板框也可正常显示。
- 历史快照类型、其他 EasyEDA 版本、复杂分区/拼板和未覆盖的源格式仍可能不支持。程序应给出明确错误；不承诺任意 `.eprj2` 都可读。
- KiCad、Altium 保留置灰入口；EasyEDA 标准版、Gerber 单独导入暂未实现。Gerber 样例仅用于独立核验。
- 顶底面变换有自动测试，但给定样例底面没有贴装器件，底面打印件尚无实物验证。
- 可手动移动单槽和标注；仍不支持拆盘或自动优化布局。少量元件可通过“忽略”手动排除。

## 样例验证结果

提供的工程还原出 **98 个器件**：91 个贴装、5 个插装、2 个按工程属性忽略。底面 4 个器件全部是插装，因此底面置灰。

Gerber 飞针文件的 417 条记录含有大量 `PAD…` 条目，不能当成 417 个器件。98 个真实器件的位号、坐标、旋转与板面已逐一核对一致。

- PCB：约 179.3 × 76 mm，四角半径 5 mm。
- 默认定位夹具：约 185.3 × 82 × 2.72 mm。
- 备料盘按建议尺寸、单边间隙 0.5 mm、最小隔墙 1 mm：原位置 88 对冲突；所测试的 2 倍间距下无冲突，约 347.5 × 124.8 mm。该尺寸超过当前 256 × 256 mm 默认打印范围。
- 原位置 88 对冲突中有 38 对槽实际相交；在临时 1000 mm 打印范围、确认建议尺寸的**软件验证条件**下，连通槽模型已导出，STEP 回读有效且 STL 网格闭合。结果见 `output/validation/overlap_validation.json`。
- 使用本轮验证备料盘 STL（333,148 个三角形），本机原生 VTK 预览的单次旋转基准约 154.8 fps，仅作当前机器上的性能参考。输入网格与预览边界一致；窗口缩放、左键平移、右键旋转、中键忽略均通过检查，滚轮缩放时鼠标下的世界点保持在原屏幕位置。结果见 `output/validation/preview_benchmark.json`。
- 完整备料盘的软件验证临时使用了 1000 mm 打印范围，并接受建议尺寸以验证几何链路。`output/validation` 中对应模型仅是验证样件，不代表你已确认器件尺寸或打印设备可用。

自动检查包含输入只读、历史记录、坐标/角度、圆弧、底面变换、冲突与参数错误、实体有效性、STEP 回读、STL 闭合/流形边/尺寸/体积、Qt 导入/板面置灰/配置恢复/模型失效机制。

尚未完成的实际验收：CATIA 导入及编辑、切片软件载入、打印平整度、PCB/钢网试配、刮刀通行和元件取放。自动检查不能替代这些步骤。

## 开发检查

使用 Python 3.12 在本目录运行：

```powershell
py -3.12 -m unittest discover -s tests -v
py -3.12 tests/ui_smoke.py
py -3.12 tests/bench_preview.py output/validation/<已有备料盘文件夹>/<模型名>.stl
```

第二项需在可显示窗口的 Windows 桌面运行，会在 `output/validation` 生成界面截图、模型与验证报告；完整备料盘生成可能需要约一分钟或更长。
